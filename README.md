# Sistema de Futebol

Projeto para gerenciamento de informações relacionadas ao futebol, desenvolvido com foco nos fundamentos da Programação Orientada a Objetos (POO).

## Objetivo

O sistema busca representar entidades e regras comuns do futebol, como jogadores, equipes, partidas e competições, por meio de classes e relacionamentos entre objetos.

## Conceitos de POO

- Abstração;
- Encapsulamento;
- Herança;
- Polimorfismo;
- Associação e composição entre objetos.

## Funcionalidades esperadas

- Cadastro e gerenciamento de equipes;
- Cadastro de jogadores;
- Organização de partidas;
- Registro de resultados;
- Acompanhamento de competições e classificações.

## Como executar

Clone o repositório e acesse a pasta do projeto:

```bash
git clone <URL_DO_REPOSITORIO>
cd POO-Sistema-Futebol
```

Em seguida, execute o projeto utilizando o ambiente e os comandos correspondentes à linguagem e à ferramenta de build adotadas.

## Estrutura do projeto

As classes devem ser organizadas de acordo com suas responsabilidades, mantendo o código modular, reutilizável e de fácil manutenção.
